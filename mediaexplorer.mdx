Handling gigabytes of location photos, reference videos, and storyboard frames is crucial for film production. The CineLog Media Explorer provides comprehensive file management capabilities, powered by an intelligent upload engine designed to keep you working smoothly even when your internet connection is poor.

## Detailed Usage & Workflows

### Intelligent File Uploads

Instant Availability (Previs)

Because CineLog favors your local device, the app instantly generates an optimized local thumbnail so you can continue sorting, viewing, and organizing your Shots immediately. You never have to wait for an upload to finish to keep working.

Background Sync

The app securely streams the heavy original file directly to cloud storage in the background.

Recovery

If you lose connection mid-upload, CineLog queues the file. A specialized background service automatically recovers stalled transfers silently across sessions.

### Operating the Interfaces

#### Full Media Explorer

Reached from the **More** menu in the project navigation. This is the project-wide view: everything you've uploaded, filterable by feature or by status, with the storage totals for the project.

Tap a file and it opens full screen, where you can pan and zoom it and arrow between the rest. Selecting is something you ask for rather than something a tap does by accident: hold a card on touch, or `Cmd`-click it on a Mac and `Ctrl`-click on Windows. Once one card is selected the list is in selection mode and a plain tap adds and removes cards, the same as every other list in CineLog. With a selection made, `Delete` or `Backspace` removes the lot.

On desktop there's an **Upload Folder** button beside Upload Files. Point it at a folder and it walks the whole thing, subfolders included, and takes the media it recognises. Anything that isn't an image, a video, an audio file or a PDF is skipped, so a folder with a stray spreadsheet in it still uploads cleanly.

On a phone the upload button asks first: **Files** reaches your file system, **Photo Library** reaches the camera roll and brings those pictures in at their original size rather than resizing them down.

#### Simplified Feature Media Screen

Opened straight from a feature, like the previs button on a shot. It's a light view scoped to that one item, and it splits into two tabs.

**Assigned** shows the files already on this item, in the order you put them, and you can drag to reorder them there. **Library** shows the rest of the project's media so you can attach something you've already uploaded.

Attaching from the Library doesn't move the file or copy it. The same image can sit on shot 3 and shot 7 at once, and a card that's in use more than once says so on its corner, so you can tell a shared reference from a one-off before you delete anything.

Upload works from either tab, and the button says which one you're in: from Library it uploads to the project pool, from Assigned it uploads and attaches in one go.

#### Choosing where a previs comes from

When you add a previs to a shot, CineLog asks where the image should come from before it opens any picker, because the two answers lead to completely different places.

**Upload from Phone** (it reads Tablet or Computer to match what you're on) opens your device's picker for a new file. **Choose from Media Library** opens the project's library instead, so you can attach an image that's already in the project rather than uploading a second copy of it.

The chooser shows up on every platform. Only its dress changes: a sheet from the bottom on a phone, a dialog on a tablet, a small card under the button on desktop.

## Visual States & Offline Awareness

Each media thumbnail always shows a status badge in the bottom-right corner with two icons that indicate availability:

#### Offline Pin

Always visible in the bottom-right badge. Appears bright when the file is available on your device, dimmed when it is not stored locally.

#### Cloud Done

Always visible in the bottom-right badge, next to the offline pin. Appears bright when synced to the cloud CDN, dimmed when not yet uploaded.

## Pro-Tips & Platform Specifics

### Offline Scouting

If you take location scouting photos without an internet connection, you can upload them entirely within CineLog. The app stores them locally, links them to your scenes, and will automatically queue the background upload once you reach an area with cell service.

### Multi-Select Filtering

When managing large numbers of rejected assets in the Full Media Explorer, use the multi-select capability to batch delete unused files in one sweep to free up your storage quota.
