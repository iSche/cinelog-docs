Los usuarios de Mac ven `Cmd`; los usuarios de Windows sustituyen por `Ctrl`. El diálogo dentro de la app que se abre con `Cmd / Ctrl + K` es una referencia similar, mantenida por separado a mano, así que puede quedarse desactualizada respecto a esta página.

El teléfono no muestra una referencia de atajos: no hay un diálogo dentro de la app para el teléfono, ya que el uso en teléfono no suele involucrar atajos de teclado. Los usuarios de tablet con un teclado de hardware pueden usar todos los atajos listados aquí.

## Global

- `[` — alternar la barra lateral izquierda (expandida ↔ colapsada)
- `Cmd / Ctrl + K` — abrir el diálogo de atajos de teclado
- `Cmd / Ctrl + Shift + M` — alternar tema (claro / oscuro)

## Lista de planos (Lineal y Producción)

- `Cmd / Ctrl + N` — añadir un plano (o un banner si estás en la vista Producción)
- `Cmd / Ctrl + F` — entrar en [Modo Focus](/es/guides/shot-list/focus-mode)
- `Shift + D` — alternar [Ajustes de Visualización](/es/guides/shot-list/display-settings)
- `Shift + L` — alternar diseño de columna (ajustado ↔ desplazamiento)
- `Shift + M` — alternar altura de fila compacta ↔ expandida
- `Shift + S` — alternar la barra lateral del guion en la vista Lineal (o abrir el selector de escenas en Modo Focus)
- `1` a `9` — alternar visibilidad de las primeras nueve columnas después de las columnas fijas Estado / Plano / Día
- `Esc` — limpiar la selección actual
- `Delete` / `Backspace` — eliminar por lotes los elementos seleccionados

## Modo Focus

- `Cmd / Ctrl + N` — añadir un plano a la escena enfocada
- `Cmd / Ctrl + F` o `Cmd / Ctrl + B` — salir del Modo Focus
- `Shift + S` — abrir el diálogo selector de escenas
- `→` / `←` — reemplazar el foco con la escena siguiente / anterior
- `Cmd + →` / `Cmd + ←` — añadir la escena siguiente / anterior al foco (multi-escena)

## Editor de guion

- `Cmd / Ctrl + 1` a `7` — establecer el tipo del párrafo actual (1 encabezado de escena, 2 personaje, 3 diálogo, 4 acción, 5 acotación, 6 transición, 7 letra de canción)
- `Cmd / Ctrl + B` / `I` / `U` — negrita / cursiva / subrayado
- `Cmd / Ctrl + E` — establecer el párrafo actual al tipo de elemento de texto centrado (no un alternador de alineación general)
- `Cmd / Ctrl + I` — con el cursor sobre texto, alterna la cursiva. En caso contrario, inicia una importación de guion (el selector de archivos y la [revisión de importación](/es/guides/importing-scripts)) — igual que el botón **Import**, que lleva el atajo en su etiqueta
- `Shift + Return` — salto de línea dentro del elemento actual
- `Shift + P` — Poblar desde el Guion (se ejecuta aquí en el Editor de Guion; inerte en la lista de planos)

### Zoom

- `Cmd / Ctrl + =` / `Cmd / Ctrl + -` — acercar / alejar (pasos del 25 %, del 50 al 200 %)
- `Cmd / Ctrl + 0` — restablecer el zoom para ajustar al ancho
- `Cmd / Ctrl + scroll` — zoom sobre el puntero (el pellizco también funciona)

### Portada

- `Tab` / `Shift + Tab` — campo siguiente / anterior de la portada, con el valor preseleccionado; `Tab` en el último campo entra en el cuerpo del guion

## Editor de etiquetas del desglose

- `1` a `9` — elegir una de las primeras nueve categorías (mientras ningún campo tiene el foco)
- `Tab` — saltar al campo Element con el texto seleccionado
- `Enter` — guardar la etiqueta
- `Esc` — cerrar sin guardar

## Exportaciones

- `Cmd / Ctrl + P` — exportar la vista actual a PDF en la lista de planos y el storyboard; en el Guion AV abre el diálogo de compartir en modo exportación. No está asignado en las órdenes de rodaje — usa el botón Exportar en la barra de menú superior de la orden de rodaje en su lugar.

## Notas

- Algunos atajos son sensibles al contexto: `Shift + S` y `Cmd + N` hacen cosas distintas dependiendo de la vista activa. Las listas anteriores indican ambos comportamientos.
- El diálogo dentro de la app (`Cmd / Ctrl + K`) muestra la mayoría de estos atajos, pero no todos — no tiene sección de Guion AV, y su lista se mantiene a mano, así que puede quedarse desactualizada respecto a esta página.
