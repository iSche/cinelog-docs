Si has llegado buscando una de estas, no está donde miras — porque aún no existe. Esta página se mantiene al día para que los usuarios no pierdan tiempo buscando cosas que no están ahí.

## Aún no en la app

- **Deshacer / rehacer en la lista de planos.** Las ediciones se aplican inmediatamente y se sincronizan vía CineSync. No hay pila de deshacer. Si eliminas la escena equivocada, contacta con soporte — el historial del lado del servidor a veces puede recuperarla.

- **Copiar / pegar / duplicar planos o escenas.** Añade un nuevo plano con `Cmd / Ctrl + N` o el botón `+`. No hay portapapeles para planos o escenas.

- **Búsqueda de texto dentro de la lista de planos.** Usa [Modo Focus](/es/guides/shot-list/focus-mode) para filtrar a escenas específicas, o los selectores de visibilidad de columnas (`1` a `9`) para reducir lo visible.

- **Selección por rango en móvil.** El escritorio tiene `Shift + Click`; el móvil no tiene equivalente. Selecciona una fila a la vez.
