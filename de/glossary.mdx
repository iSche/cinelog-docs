Nur einzeilige Definitionen. Für das Verhalten folge dem Link.

- **Einstellung (Shot)** — ein geplantes Kamera-Setup. Lebt innerhalb einer Szene.
- **Szene** — eine Gruppe von Einstellungen, die einen erzählerischen Kontext teilen. Nummeriert.
- **Szenenblock** — die visuelle Gruppierung der Einstellungen einer Szene in der Liste, mit dem Szenen-Header als erster Zeile.
- **Banner** — eine Nicht-Einstellungs-Zeile in der Drehtage-Ansicht, die eine Essenspause, einen Company Move oder Wrap markiert. Siehe [Linear vs Drehtage](/de/guides/shot-list/linear-vs-production).
- **Lineare Ansicht** — Drehbuchreihenfolge-Ansicht der Einstellungsliste.
- **Drehtage-Ansicht** — Drehtag-Reihenfolge-Ansicht der Einstellungsliste. Hat Szenen-bezogene Auswahlregeln; siehe [Linear vs Drehtage](/de/guides/shot-list/linear-vs-production).
- **Drehtag (Production Day)** — ein geplanter Drehtag. Jeder Drehtag erscheint als Untereintrag in der Seitenleiste.
- **Fokus-Modus** — Einzel- oder Mehr-Szenen-Filter auf der Einstellungsliste. Siehe [Fokus-Modus](/de/guides/shot-list/focus-mode).
- **Auswahlmodus** — der persistente Modus, in den eine Liste wechselt, wenn eine oder mehrere Zeilen ausgewählt sind. Gesten verhalten sich anders; siehe [Die Grundlagen](/de/guides/introduction#3-selecting-rows).
- **Previs** — ein Referenzbild oder Video-Frame, das an eine Einstellung angehängt ist.
- **Storyboard-Ansicht** — ein gespeichertes Layout / Filter für das Storyboard. Eine Szene kann mehrere haben.
- **Cast & Crew-Ansicht** — ein gespeicherter Filter auf das Cast & Crew-Verzeichnis.
- **CineSync** — die Sync-Engine, die Bearbeitungen am Gerät speichert und sie an den Server und andere Geräte verteilt.
