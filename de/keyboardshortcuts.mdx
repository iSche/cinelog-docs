Mac-Nutzer sehen `Cmd`; Windows-Nutzer ersetzen es durch `Ctrl`. Der In-App-Dialog, der mit `Cmd / Ctrl + K` geöffnet wird, ist eine ähnliche Referenz, separat von Hand gepflegt, sodass er hinter dieser Seite zurückbleiben kann.

Das Smartphone zeigt keine Hotkey-Referenz an – es gibt keinen In-App-Dialog für das Telefon, da die Nutzung am Smartphone normalerweise keine Tastenkürzel beinhaltet. Tablet-Nutzer mit einer Hardware-Tastatur können jedes hier gelistete Kürzel verwenden.

## Global

- `[` — linke Seitenleiste umschalten (ausgeklappt ↔ eingeklappt)
- `Cmd / Ctrl + K` — Dialog der Tastenkürzel öffnen
- `Cmd / Ctrl + Shift + M` — Theme umschalten (hell / dunkel)

## Einstellungsliste (Linear und Drehtage)

- `Cmd / Ctrl + N` — Einstellung hinzufügen (oder Banner in der Drehtage-Ansicht)
- `Cmd / Ctrl + F` — [Fokus-Modus](/de/guides/shot-list/focus-mode) starten
- `Shift + D` — [Anzeige-Einstellungen](/de/guides/shot-list/display-settings) umschalten
- `Shift + L` — Spalten-Layout umschalten (fit ↔ scroll)
- `Shift + M` — kompakte ↔ erweiterte Zeilenhöhe umschalten
- `Shift + S` — Drehbuch-Seitenleiste in linearer Ansicht umschalten (oder Szenen-Picker im Fokus-Modus öffnen)
- `1` bis `9` — Sichtbarkeit der ersten neun Spalten nach den angehefteten Spalten Status / Einstellung / Tag umschalten
- `Esc` — aktuelle Auswahl aufheben
- `Delete` / `Backspace` — ausgewählte Elemente in Masse löschen

## Fokus-Modus

- `Cmd / Ctrl + N` — Einstellung zur fokussierten Szene hinzufügen
- `Cmd / Ctrl + F` oder `Cmd / Ctrl + B` — Fokus-Modus verlassen
- `Shift + S` — Szenen-Picker-Dialog öffnen
- `→` / `←` — Fokus durch nächste / vorherige Szene ersetzen
- `Cmd + →` / `Cmd + ←` — nächste / vorherige Szene zum Fokus hinzufügen (Multi-Szenen)

## Drehbuch-Editor

- `Cmd / Ctrl + 1` bis `7` — Typ des aktuellen Absatzes setzen (1 Szenenüberschrift, 2 Figur, 3 Dialog, 4 Action, 5 Klammerzusatz, 6 Übergang, 7 Songtext)
- `Cmd / Ctrl + B` / `I` / `U` — fett / kursiv / unterstrichen
- `Cmd / Ctrl + E` — den aktuellen Absatz auf den zentrierten-Text-Elementtyp setzen (kein allgemeines Ausrichtungs-Toggle)
- `Cmd / Ctrl + I` — steht der Cursor auf Text, schaltet es kursiv um. Sonst startet es einen Drehbuch-Import (die Dateiauswahl und das [Import-Review](/de/guides/importing-scripts)) – dasselbe wie der **Import**-Button, der das Kürzel auf seinem Label trägt
- `Shift + Return` — Zeilenumbruch innerhalb des aktuellen Elements
- `Shift + P` — Aus Drehbuch befüllen (läuft hier im Drehbuch-Editor; inaktiv auf der Einstellungsliste)

### Zoom

- `Cmd / Ctrl + =` / `Cmd / Ctrl + -` — hinein- / herauszoomen (25-%-Schritte, 50–200 %)
- `Cmd / Ctrl + 0` — Zoom auf Breite anpassen zurücksetzen
- `Cmd / Ctrl + Scrollen` — am Zeiger zoomen (Pinch funktioniert auch)

### Titelseite

- `Tab` / `Shift + Tab` — nächstes / vorheriges Titelseiten-Feld, mit vorausgewähltem Wert; `Tab` im letzten Feld setzt dich in den Drehbuchtext

## Tag-Editor des Drehbuchauszugs

- `1` bis `9` — eine der ersten neun Kategorien wählen (solange kein Feld den Fokus hat)
- `Tab` — mit ausgewähltem Text ins Element-Feld springen
- `Enter` — den Tag speichern
- `Esc` — schließen, ohne zu speichern

## Exporte

- `Cmd / Ctrl + P` — aktuelle Ansicht als PDF exportieren auf der Einstellungsliste und im Storyboard; im AV-Skript öffnet es den Share-Dialog im Export-Modus. Nicht bei Dispositionen belegt – nutze dort stattdessen den Export-Button in der oberen Menüleiste der Disposition.

## Hinweise

- Einige Kürzel sind kontextabhängig — `Shift + S` und `Cmd + N` tun je nach aktiver Ansicht unterschiedliche Dinge. Die Listen oben dokumentieren beide Verhaltensweisen.
- Der In-App-Dialog (`Cmd / Ctrl + K`) zeigt die meisten dieser Kürzel, aber nicht alle – er hat keinen AV-Skript-Abschnitt, und seine Liste wird von Hand gepflegt, sodass er hinter dieser Seite zurückbleiben kann.
