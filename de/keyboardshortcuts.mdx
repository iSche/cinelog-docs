Mac-Nutzer sehen `Cmd`; Windows-Nutzer ersetzen es durch `Ctrl`. Der In-App-Dialog, der mit `Cmd / Ctrl + K` geöffnet wird, listet dieselben Kürzel auf.

Das Smartphone zeigt keine Hotkey-Referenz an – es gibt keinen In-App-Dialog für das Telefon, da die Nutzung am Smartphone normalerweise keine Tastenkürzel beinhaltet. Tablet-Nutzer mit einer Hardware-Tastatur können jedes hier gelistete Kürzel verwenden.

## Global

- `[` — linke Seitenleiste umschalten (ausgeklappt ↔ eingeklappt)
- `Cmd / Ctrl + K` — Dialog der Tastenkürzel öffnen
- `Cmd / Ctrl + Shift + M` — Theme umschalten (hell / dunkel)

## Einstellungsliste (Linear und Drehtage)

- `Cmd / Ctrl + N` — Einstellung hinzufügen (oder Banner in der Drehtage-Ansicht)
- `Cmd / Ctrl + F` — [Fokus-Modus](/de/guides/shot-list/focus-mode) starten
- `Shift + D` — [Anzeige-Einstellungen](/de/guides/shot-list/display-settings) umschalten
- `Shift + L` — Spalten-Layout umschalten (fit ↔ scroll)
- `Shift + M` — kompakte ↔ erweiterte Zeilenhöhe umschalten
- `Shift + S` — Drehbuch-Seitenleiste in linearer Ansicht umschalten (oder Szenen-Picker im Fokus-Modus öffnen)
- `Shift + P` — Aus Drehbuch befüllen
- `1` bis `9` — Sichtbarkeit der ersten neun Spalten nach den angehefteten Spalten Status / Einstellung / Tag umschalten
- `Esc` — aktuelle Auswahl aufheben
- `Delete` / `Backspace` — ausgewählte Elemente in Masse löschen

## Fokus-Modus

- `Cmd / Ctrl + N` — Einstellung zur fokussierten Szene hinzufügen
- `Cmd / Ctrl + F` oder `Cmd / Ctrl + B` — Fokus-Modus verlassen
- `Shift + S` — Szenen-Picker-Dialog öffnen
- `→` / `←` — Fokus durch nächste / vorherige Szene ersetzen
- `Cmd + →` / `Cmd + ←` — nächste / vorherige Szene zum Fokus hinzufügen (Multi-Szenen)

## Drehbuch-Editor

- `Cmd / Ctrl + 1` bis `7` — Typ des aktuellen Absatzes setzen (1 Szenenüberschrift, 2 Figur, 3 Dialog, 4 Action, 5 Klammerzusatz, 6 Übergang, 7 Songtext)
- `Cmd / Ctrl + B` / `I` / `U` — fett / kursiv / unterstrichen
- `Cmd / Ctrl + E` — zentriert ausrichten

## Exporte

- `Cmd / Ctrl + P` — aktuelle Ansicht als PDF exportieren (Einstellungsliste, Storyboard oder Disposition – passt sich an die aktive Ansicht an)

## Hinweise

- Einige Kürzel sind kontextabhängig — `Shift + S` und `Cmd + N` tun je nach aktiver Ansicht unterschiedliche Dinge. Die Listen oben dokumentieren beide Verhaltensweisen.
- Der In-App-Dialog (`Cmd / Ctrl + K`) listet jedes Kürzel auf und wird mit jedem Release aktualisiert.
