CineLog's Script Editor is a professional screenplay editing system built for modern film production workflows. Import scripts from multiple formats, edit with real-time Fountain syntax support, track analytics, and seamlessly integrate with your shot list—all with industry-standard formatting and collaborative features.

## Professional Editing Experience

<Aside type="tip">
The Script Editor provides a professional screenplay editing environment with industry-standard formatting and powerful automation features that streamline your writing workflow.
</Aside>

<Steps>
<ol>

<li>

**Smart Element Detection**

Automatic classification of scene headings (INT./EXT.), character names, dialogue, action, and transitions with real-time visual styling. Type naturally and watch your script format itself professionally.

</li>
<li>

**Manual Override Controls**

Precise control with hotkeys: **Cmd+1** Scene Heading, **Cmd+2** Character, **Cmd+3** Dialogue, **Cmd+4** Action, **Cmd+5** Parenthetical, **Cmd+6** Transition, **Cmd+7** Lyrics, **Cmd+E** Centered text element.

</li>
<li>

**Fountain Support**

Core Fountain support with forced syntax elements (@Character, !Action, .Scene) and text formatting (\*italics\*, \*\*bold\*\*, \_underline\_). Sections (#), synopses (=), inline notes ([[ ]]), page breaks (===), and side-by-side dual dialogue are not supported.

</li>
<li>

**Industry Typography**

Character-precise positioning with 12-point Courier Prime font, proper margins, and element-specific indentation following professional screenplay standards.

</li>

</ol>
</Steps>

## Import & Analytics

### Multi-Format Script Import

Need to bring in writing from an older app? Click the **Import** button in the Script Editor’s top menu bar to import and convert an existing script. Our universal parser intelligently extracts scenes, characters, and dialogue geometry from your original document, applying standard Fountain formatting automatically.

<CardGrid>
<Card title="Final Draft (.fdx)">
  Professional XML parsing with complete metadata preservation, character formatting, and scene properties.
</Card>

<Card title="Fountain (.fountain)">
  Native format support with forced elements, title page parsing, and boneyard comment stripping.
</Card>

<Card title="PDF Scripts">
  Text extraction from PDF screenplays, with a configuration step for how the text is pulled in.
</Card>

<Card title="Plain Text (.txt)">
  Intelligent heuristic detection using scene patterns, character recognition, and context clues.
</Card>

<Card title="Rich Text (.rtf)">
  RTF parsing with style extraction and clean text conversion for screenplay formatting.
</Card>
</CardGrid>

### Real-Time Script Analytics

A stats sidebar on the desktop editor updates live as you write. It shows five metrics: Pages, Scenes, Lines, Words, and Characters.

<CardGrid>
<Card title="Estimated Page Count">

</Card>

<Card title="Scenes & Lines">
  Live counts of the scenes in the document and the total number of lines.
</Card>

<Card title="Words & Characters">
  Live totals for word count and character count as you type.
</Card>

## Shot List Integration

<Aside type="tip">
Bridge the gap between script and production with intelligent shot list population that analyzes your script content and creates comprehensive coverage automatically.
</Aside>

<Steps>
<ol>

<li>

**Content Analysis**

The system analyzes your script content to understand scenes, character interactions, action sequences, and dialogue moments.

</li>
<li>

**Intelligent Shot Estimation**

Creates coverage shots based on content type—action coverage for sequences, dialogue coverage for conversations, and reaction shots for character moments.

</li>
<li>

**Smart Placement**

Shots are placed near their source content with descriptions that include actual script text, helping directors understand WHY each shot is needed.

</li>
<li>

**Flexible Population**

Choose from Replace or Merge modes to integrate with existing shot lists while preserving your manual customizations.

</li>

</ol>
</Steps>

<Aside type="tip" title="Population Benefits">
-   **Content-Aware Descriptions**: Shot descriptions include actual script content instead of generic text
-   **Element-Type Based Coverage**: Different shot types based on whether content is action, dialogue, or reactions
-   **Smart Shot Placement**: Coverage shots intelligently placed near source content, not dumped at scene end
-   **Actionable Direction**: Help directors understand the purpose of each shot with content context
</Aside>
