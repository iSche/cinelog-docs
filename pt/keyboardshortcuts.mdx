Usuários de Mac veem `Cmd`; usuários de Windows substituem por `Ctrl`. O diálogo no app aberto com `Cmd / Ctrl + K` é gerado a partir da mesma referência; os dois ficam em sincronia.

O celular não exibe uma referência de atalhos — não há diálogo no app no celular, já que o uso em celular normalmente não envolve atalhos de teclado. Usuários de tablet com teclado físico podem usar todos os atalhos listados aqui.

## Global

- `[` — alterna a barra lateral esquerda (expandida ↔ recolhida)
- `Cmd / Ctrl + K` — abre o diálogo de atalhos de teclado
- `Cmd / Ctrl + Shift + M` — alterna o tema (claro / escuro)

## Decupagem (Linear e Produção)

- `Cmd / Ctrl + N` — adiciona um plano (ou um banner se estiver na visualização Produção)
- `Cmd / Ctrl + F` — entra no [Modo Foco](/pt/guides/shot-list/focus-mode)
- `Shift + D` — alterna as [Configurações de Exibição](/pt/guides/shot-list/display-settings)
- `Shift + L` — alterna o layout de colunas (ajustado ↔ rolagem)
- `Shift + M` — alterna entre altura de linha compacta ↔ expandida
- `Shift + S` — alterna a barra lateral do roteiro na visualização Linear (ou abre o seletor de cenas no Modo Foco)
- `Shift + P` — Popular a partir do Roteiro
- `1` a `9` — alterna a visibilidade das colunas 1 a 9
- `Esc` — limpa a seleção atual
- `Delete` / `Backspace` — exclui em lote os itens selecionados

## Modo Foco

- `Cmd / Ctrl + N` — adiciona um plano à cena focada
- `Cmd / Ctrl + F` ou `Cmd / Ctrl + B` — sai do Modo Foco
- `Shift + S` — abre o diálogo de seleção de cena
- `→` / `←` — substitui o foco pela próxima / cena anterior
- `Cmd + →` / `Cmd + ←` — adiciona a próxima / cena anterior ao foco (multi-cena)

## Editor de Roteiro

- `Cmd / Ctrl + 1` a `7` — define o tipo do parágrafo atual (cabeçalho de cena, ação, diálogo, …)
- `Cmd / Ctrl + B` / `I` / `U` — negrito / itálico / sublinhado
- `Cmd / Ctrl + E` — alinhar ao centro

## Exportações

- `Cmd / Ctrl + P` — exporta a visualização atual para PDF (decupagem, storyboard ou ordem do dia — adapta-se ao que você está vendo)

## Notas

- Alguns atalhos são sensíveis ao contexto — `Shift + S` e `Cmd + N` fazem coisas diferentes dependendo da visualização ativa. As listas acima descrevem ambos os comportamentos.
- O diálogo no app (`Cmd / Ctrl + K`) é a única fonte de verdade e se mantém atualizado a cada release.
