Les utilisateurs Mac voient `Cmd` ; les utilisateurs Windows substituent `Ctrl`. La boîte de dialogue intégrée ouverte avec `Cmd / Ctrl + K` est une référence similaire, maintenue séparément à la main, donc elle peut être en retard par rapport à cette page.

Le téléphone n'expose pas de référence de raccourcis — il n'y a pas de boîte de dialogue intégrée pour téléphone, puisque l'usage téléphone n'implique généralement pas de raccourcis clavier. Les utilisateurs de tablette avec un clavier matériel peuvent utiliser tous les raccourcis listés ici.

## Global

- `[` — basculer la barre latérale gauche (étendue ↔ réduite)
- `Cmd / Ctrl + K` — ouvrir la boîte de dialogue des raccourcis clavier
- `Cmd / Ctrl + Shift + M` — basculer le thème (clair / sombre)

## Découpage Technique (Linéaire et Production)

- `Cmd / Ctrl + N` — ajouter un plan (ou une bannière en vue Production)
- `Shift + D` — basculer les [Paramètres d'affichage](/fr/guides/shot-list/display-settings)
- `Shift + L` — basculer la disposition des colonnes (ajustée ↔ défilante)
- `Shift + M` — basculer entre hauteur de ligne compacte ↔ étendue
- `Shift + S` — basculer le panneau latéral du scénario. Vue Linéaire uniquement, il ne fait rien en Production
- `1` à `9` — basculer la visibilité des neuf premières colonnes après les colonnes épinglées Statut / Plan / Jour
- `Esc` — effacer la sélection actuelle
- `Delete` / `Backspace` — suppression groupée des éléments sélectionnés

## Logiciel de Scénario

- `Cmd / Ctrl + 1` à `7` — définir le type du paragraphe actuel (1 en-tête de scène, 2 personnage, 3 dialogue, 4 action, 5 parenthèse, 6 transition, 7 paroles)
- `Cmd / Ctrl + B` / `I` / `U` — gras / italique / souligné
- `Cmd / Ctrl + E` — définir le paragraphe actuel sur le type d'élément texte centré (pas une bascule d'alignement générale)
- `Cmd / Ctrl + I` — avec le curseur sur du texte, bascule l'italique. Sinon, lance un import de scénario (le sélecteur de fichiers et la [vérification d'import](/fr/guides/importing-scripts)) — comme le bouton **Import**, dont l'intitulé porte le raccourci
- `Shift + Return` — saut de ligne à l'intérieur de l'élément actuel
- `Shift + P` — Remplir depuis le scénario (s'exécute ici dans le Logiciel de Scénario ; inerte sur le découpage technique)

### Zoom

- `Cmd / Ctrl + =` / `Cmd / Ctrl + -` — zoom avant / arrière (paliers de 25 %, 50–200 %)
- `Cmd / Ctrl + 0` — réinitialiser le zoom pour ajuster à la largeur
- `Cmd / Ctrl + molette` — zoomer au niveau du pointeur (le pincement fonctionne aussi)

### Page de titre

- `Tab` / `Shift + Tab` — champ suivant / précédent de la page de titre, avec la valeur présélectionnée ; `Tab` sur le dernier champ entre dans le corps du scénario

## Éditeur d'étiquettes de dépouillement

- `1` à `9` — choisir l'une des neuf premières catégories (tant qu'aucun champ n'a le focus)
- `Tab` — sauter au champ Élément avec le texte sélectionné
- `Enter` — enregistrer l'étiquette
- `Esc` — fermer sans enregistrer

## Exports

- `Cmd / Ctrl + P` — exporter la vue actuelle en PDF sur le découpage technique et le storyboard ; sur le Script AV, il ouvre la boîte de dialogue de partage en mode export. Non lié sur les feuilles de service — utilise plutôt le bouton Exporter dans la barre de menu supérieure de la feuille de service.

## Notes

- `Cmd / Ctrl + N` est sensible au contexte : un plan en vue Linéaire, une bannière en Production. `Shift + S` ne fonctionne qu'en Linéaire. La liste ci-dessus note les deux.
- La boîte de dialogue intégrée (`Cmd / Ctrl + K`) affiche la plupart de ces raccourcis, mais pas tous — elle n'a pas de section Script AV, et sa liste est maintenue à la main, donc elle peut être en retard par rapport à cette page.
