Si tu es venu chercher l'un de ces éléments, il n'est pas là où tu cherches — parce qu'il n'existe pas encore. Cette page est maintenue à jour pour que les utilisateurs ne perdent pas de temps à chercher des choses qui ne sont pas là.

## Pas encore dans l'application

- **Annuler / Rétablir dans le découpage technique.** Les modifications sont validées immédiatement et synchronisées via CineSync. Il n'y a pas de pile d'annulation. Si tu supprimes la mauvaise scène, contacte le support — l'historique côté serveur peut parfois la récupérer.

- **Copier / Coller / Dupliquer des plans ou scènes.** Ajoute un nouveau plan via `Cmd / Ctrl + N` ou le bouton `+`. Il n'y a pas de presse-papiers pour les plans ou scènes.

- **Recherche textuelle dans le découpage technique.** Utilise le [mode Focus](/fr/guides/shot-list/focus-mode) pour filtrer vers des scènes spécifiques, ou les bascules de visibilité des colonnes (`1` à `9`) pour réduire ce qui est visible.

- **Sélection par plage sur appareils tactiles uniquement.** Les plages `Shift + Click` fonctionnent sur le bureau et sur les tablettes avec un clavier physique connecté. Sur les appareils tactiles uniquement, sélectionne une ligne à la fois en mode sélection.

- **Déverrouiller un scénario verrouillé.** Une fois les numéros de scène verrouillés, il n'y a pas de déverrouillage — omets des scènes, révise des pages, ou adopte de nouveaux numéros via un [import](/fr/guides/importing-scripts). Cela reflète le fonctionnement réel des productions : renuméroter après diffusion est un travail de réparation.

- **Catégories de dépouillement personnalisées.** Le [Dépouillement](/fr/breakdown) est livré avec douze catégories fixes. Utilise Notes de production comme fourre-tout en attendant.

- **Renommer ou supprimer un rôle personnalisé.** Tu peux créer des rôles d'équipe personnalisés, mais l'application ne permet pas encore de les renommer ou de les supprimer — nomme-les donc tels que la feuille de service doit les imprimer.

## Statut

Cette liste est revue chaque trimestre. Les éléments sont retirés lorsqu'ils sont livrés.
