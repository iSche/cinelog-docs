Définitions d'une ligne uniquement. Pour le comportement, suis le lien.

- **Plan** — une prise de vue planifiée. Vit à l'intérieur d'une scène.
- **Scène** — un groupe de plans qui partagent un contexte narratif. Numérotée.
- **Bloc de scène** — le regroupement visuel des plans d'une scène dans la liste, avec l'en-tête de scène comme première ligne.
- **Bannière** — une ligne non-plan en vue Production qui marque une pause repas, un déplacement d'équipe ou une fin de journée. Voir [Linéaire vs Production](/fr/guides/shot-list/linear-vs-production).
- **Vue Linéaire** — vue du découpage technique dans l'ordre du scénario.
- **Vue Production** — vue du découpage technique dans l'ordre des jours de tournage. Possède des règles de sélection à portée de scène ; voir [Linéaire vs Production](/fr/guides/shot-list/linear-vs-production).
- **Jour de production** — une journée de tournage planifiée. Chaque Jour de production apparaît comme une sous-entrée dans la barre latérale.
- **Mode Focus** — filtre mono ou multi-scènes sur le découpage technique. Voir [Mode Focus](/fr/guides/shot-list/focus-mode).
- **Mode sélection** — le mode persistant qu'une liste adopte lorsqu'une ou plusieurs lignes sont sélectionnées. Les gestes sont acheminés différemment ; voir [Les bases](/fr/guides/introduction#3-selecting-rows).
- **Prévisualisation** — une image ou un cadre vidéo de référence attaché à un plan.
- **Script AV** — le script Audio / Visuel à deux colonnes des spots chronométrés, synchronisé avec le découpage technique linéaire. Un par projet ; voir [Script AV](/fr/avscript).
- **Tour de validation** — un cycle « Send for review » du Script AV. Les commentaires et les statuts de ligne sont suivis par tour ; voir [Validation client](/fr/guides/av-script/client-review).
- **Lien de validation** — le lien Script AV partageable pour les relecteurs externes, View only ou Comment & Approve. Aucun compte requis.
- **GFX** — une entrée d'habillage graphique sur une ligne du Script AV : Lower Third, Super, Full Screen, Bug ou End Card.
- **Vue Storyboard** — une disposition / un filtre enregistré pour le storyboard. Une scène peut en avoir plusieurs.
- **Vue Casting et Équipe** — un filtre enregistré sur le répertoire Casting et Équipe.
- **CineSync** — le moteur de synchronisation qui persiste les modifications sur l'appareil et les propage vers le serveur et les autres appareils.
