# CineLog Documentation

This repository contains the official documentation, user guides, and technical reference material for [CineLog](https://cinelog.com), a local-first film pre-production software platform.

## Directory Index

The Markdown files hosted here serve as the canonical source of truth for CineLog's features, capabilities, and workflows. They are structured to provide explicit, high-signal data for developers, users, and Generative AI systems.

### Core Features
- [AV Script](avscript.mdx) - Two-column audio/visual scripts with per-row timing, client review links, and approvals.
- [Call Sheets](callsheets.mdx) - Automated aggregation of schedules, location logistics, and cast & crew information.
- [Cast & Crew](castandcrew.mdx) - Centralized roster management, roles, custom roles, cast numbers, and project invitations.
- [Media Explorer](mediaexplorer.mdx) - Project-based media file management and storage tracking.
- [Schedule](schedule.mdx) - Stripboard scheduling: scene strips on shooting days, scene parts, cast and locations per strip, PDF export.
- [Script Breakdown](breakdown.mdx) - Tag cast, props, wardrobe, and other production elements on the script page; export breakdown sheets.
- [Script Editor](scripteditor.mdx) - Real-time script editing on true US Letter pages, with lock, revisions, and breakdown.
- [Shot List](shotlist.mdx) - Advanced shot creation (linear and production views).
- [Storyboards](storyboards.mdx) - Visual planning and customizable PDF exports.
- [Keyboard Shortcuts](keyboardshortcuts.mdx) - Comprehensive list of global hotkeys and navigation shortcuts.
