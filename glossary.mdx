One-line definitions only. For behaviour, follow the link.

- **Shot** — a planned camera setup. Lives inside a scene.
- **Scene** — a group of shots that share narrative context. Numbered.
- **Scene block** — the visual grouping of a scene's shots in the list, with the scene header as its first row.
- **Banner** — a non-shot row marking a schedule event — crew call, meals, company move, estimated wrap, and other call-time events — or a custom label. Appears in Production view and on the call sheet schedule; edits in either place stay in sync. See [Linear vs Production](/guides/shot-list/linear-vs-production).
- **Linear view** — script-order view of the shot list.
- **Production view** — shoot-day order view of the shot list. Has scene-scope selection rules; see [Linear vs Production](/guides/shot-list/linear-vs-production).
- **Production Day** — a scheduled shoot day. Production view groups shots by Production Day.
- **Selection mode** — the persistent mode a list enters when one or more rows are selected. Gestures route differently; see [The basics](/guides/introduction#3-selecting-rows).
- **Previs** — a reference image attached to a shot. Images only — video can't be attached as previs.
- **AV Script** — the two-column Audio / Visual script for timed spots, kept in sync with the Linear Shot List. One per project; see [AV Script](/avscript).
- **Review round** — a numbered pass of client review of the AV Script. Each sendout to the client starts a new round and sets rows back to Review; see [Client review](/guides/av-script/client-review).
- **Review link** — the link emailed to the client for leaving feedback on the AV Script.
- **GFX** — a graphics-overlay entry attached to a shot, shown in the AV Script.
- **Storyboard View** — one of the storyboard's display modes: Linear (the default, script-order strip) or Grid. The view applies to the whole project's storyboard.
- **Cast & Crew View** — a sub-section of Cast & Crew in the navigation (e.g. Contacts).
- **CineSync** — the sync engine that persists edits to the device and propagates them to the server and other devices.
- **Breakdown** — the tagging pass that lists every production element the script calls for, category by category. See [Script Breakdown](/breakdown).
- **Element** — one item in the breakdown (a prop, a costume, a character). Tagged in one or many scenes; see [Script Breakdown](/breakdown).
- **Tag** — one occurrence of an element in the script: the underlined words in a scene.
- **Cast number** — the number a Talent slot carries, printed next to the actor on call sheets. See [Managing Cast & Crew](/guides/managing-cast-crew).
- **Talent slot** — a cast-group role slot in Cast & Crew, vacant or filled, optionally linked to a character from the breakdown.
- **Custom role** — a workspace-defined crew role, living in the Custom department. See [Managing Cast & Crew](/guides/managing-cast-crew).
- **Scene lock** — freezes scene numbers; new scenes get letter numbers (78A) and removed scenes become OMITTED. See [Script lock & revisions](/guides/script-lock-and-revisions).
- **Page lock** — freezes pagination and issues the draft; later material flows onto A-pages. See [Script lock & revisions](/guides/script-lock-and-revisions).
- **Revision** — one colored round of changes after Page Lock (Blue, Pink, Yellow…), marked with asterisks and a page-corner note.
- **Omitted scene** — a locked scene whose content is removed but whose number stays, shown as an OMITTED tombstone. Restorable.
- **Title page** — the first, unnumbered page of the script, edited in place with eight fixed fields. See [Writing & formatting](/guides/writing-formatting-scripts).
- **Import review** — the screen every script import goes through, showing each change for accept/reject before it's applied. See [Importing scripts](/guides/importing-scripts).
