One-line definitions only. For behaviour, follow the link.

- **Shot** — a planned camera setup. Lives inside a scene.
- **Scene** — a group of shots that share narrative context. Numbered.
- **Scene block** — the visual grouping of a scene's shots in the list, with the scene header as its first row.
- **Banner** — a non-shot row in Production view that marks a meal break, company move, or wrap. See [Linear vs Production](/guides/shot-list/linear-vs-production).
- **Linear view** — script-order view of the shot list.
- **Production view** — shoot-day order view of the shot list. Has scene-scope selection rules; see [Linear vs Production](/guides/shot-list/linear-vs-production).
- **Production Day** — a scheduled shoot day. Each Production Day appears as a sub-entry in the sidebar.
- **Focus mode** — single- or multi-scene filter on the shot list. See [Focus mode](/guides/shot-list/focus-mode).
- **Selection mode** — the persistent mode a list enters when one or more rows are selected. Gestures route differently; see [The basics](/guides/introduction#3-selecting-rows).
- **Previs** — a reference image or video frame attached to a shot.
- **AV Script** — the two-column Audio / Visual script view of the linear shot list. One per project; see [AV Script](/avscript).
- **Review round** — one "Send for review" cycle of the AV Script. Comments and row statuses are tracked per round; see [Client review](/guides/av-script/client-review).
- **Review link** — the shareable AV Script link for external reviewers, View only or Comment & Approve. No account needed.
- **GFX** — a graphics overlay entry on an AV Script row: Lower Third, Super, Full Screen, Bug, or End Card.
- **Storyboard View** — a saved layout / filter for the storyboard. One scene can have several.
- **Cast & Crew View** — a saved filter on the Cast & Crew directory.
- **CineSync** — the sync engine that persists edits to the device and propagates them to the server and other devices.
