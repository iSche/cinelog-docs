Display Settings controls how the shot list looks — which columns are visible, in what order, what the shots are numbered as. Settings are project-level and propagate via CineSync, so adjustments made on the desktop appear on the mobile app within seconds.

`Shift + D` toggles the Display Settings overlay.

## Column visibility

Toggle any column on or off from the Display Settings overlay. For quick changes without opening Display Settings, the number keys `1` through `9` toggle the first nine columns after the pinned Status, Shot, and Day, directly from the list view.

## Reordering columns

Reorder columns by dragging a column header on the main shot list left or right. The three pinned system columns — Status, Shot, and Day — stay locked to the leftmost positions and can't be moved.

The Display Settings overlay controls column visibility, row height, numbering format, and custom columns — not column order.

## Custom columns

Add your own columns from Display Settings by giving each a name. Custom columns hold free text. Once added, the column appears in the desktop list and in the mobile expanded view automatically — no per-platform setup. Custom columns participate in PDF export.

## Shot numbering format

Three formats are supported, shown in the overlay with live samples:

- **US** — `1A`, `1B`, `1C`. Scene + letter.
- **EU** — `1.1`, `1.2`, `2.1`.
- **UK** — `1`, `2`, `3`. Continuous through the project.

These are the same three formats the AV Script and Storyboard display settings offer, under the same names. The format is a display preference — it changes how numbers are shown without altering the underlying shots, so you can switch between formats freely and switch back at any time.

## Script sidebar, auto-scroll, and dates

Three more rows live in the overlay:

- **Script Width** — how much of the window the script sidebar takes when it's open, from 30% to 50%.
- **Script Auto-scroll** — whether the script sidebar follows along as you move through the list.
- **Date Format** — `M/D/Y`, `D/M/Y`, or `Y-M-D`. This one is app-wide: the same setting appears in the Display menus across CineLog, and changing it anywhere changes it everywhere, including exported PDFs that print dates.

## Row height and display mode

`Shift + M` toggles between compact and expanded row heights. Display Settings has a finer control if you want an in-between size.

## Sync across devices

All Display Settings are project-level and propagate via CineSync. A producer adjusting columns on their desktop will see the same column set on their iPad within seconds.

## If this isn't working

*"How do I reorder columns?"* Drag a column header on the main list. The pinned Status, Shot, and Day columns can't be moved.

*"I changed the shot number format and the numbers look different."* That's expected — it's a display-only setting. Switch back to the previous format and the original numbering reappears.

*"My custom column is on desktop but not on mobile."* It should appear automatically. Try force-quitting and reopening the mobile app. If the sync indicator shows pending changes, the new column hasn't propagated yet.
