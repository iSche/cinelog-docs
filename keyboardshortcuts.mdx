Mac users see `Cmd`; Windows users substitute `Ctrl`. The in-app dialog opened with `Cmd / Ctrl + K` is a similar reference, maintained separately by hand, so it can lag behind this page.

Phone doesn't surface a hotkeys reference — there's no in-app dialog for phone, since phone usage doesn't typically involve keyboard shortcuts. Tablet users with a hardware keyboard can use every shortcut listed here.

## Global

- `[` — toggle the left sidebar (expanded ↔ collapsed)
- `Cmd / Ctrl + K` — open the keyboard shortcuts dialog
- `Cmd / Ctrl + Shift + M` — cycle the theme: light, then dark, then system, then back to light

## Shot list (Linear and Production)

- `Cmd / Ctrl + N` — add a shot (or a banner if in Production view)
- `Shift + D` — toggle [Display Settings](/guides/shot-list/display-settings)
- `Shift + L` — toggle column layout (fit ↔ scroll)
- `Shift + M` — toggle compact ↔ expanded row height
- `Shift + S` — toggle the script side panel. Linear view only, it does nothing in Production
- `1` through `9` — toggle visibility of the first nine columns after the pinned Status / Shot / Day
- `Esc` — clear current selection
- `Delete` / `Backspace` — bulk delete selected items

## Script editor

- `Cmd / Ctrl + 1` through `7` — set the current paragraph's type (1 scene heading, 2 character, 3 dialogue, 4 action, 5 parenthetical, 6 transition, 7 lyrics)
- `Cmd / Ctrl + B` / `I` / `U` — bold / italic / underline
- `Cmd / Ctrl + E` — set the current paragraph to the centred-text element type (not a general alignment toggle)
- `Cmd / Ctrl + I` — with the caret on text, toggles italic. Otherwise it starts a script import (the file picker and the [import review](/guides/importing-scripts)) — same as the **Import** button, which carries the hotkey on its label
- `Shift + Return` — line break inside the current element
- `Shift + P` — Populate from Script (runs here in the Script Editor; inert on the shot list)

### Zoom

- `Cmd / Ctrl + =` / `Cmd / Ctrl + -` — zoom in / out (25% steps, 50–200%)
- `Cmd / Ctrl + 0` — reset zoom to fit width
- `Cmd / Ctrl + scroll` — zoom at the pointer (pinch works too)

### Title page

- `Tab` / `Shift + Tab` — next / previous title-page field, with the value pre-selected; `Tab` on the last field enters the script body

## Breakdown tag editor

- `1` through `9` — pick one of the first nine categories (while no field has focus)
- `Tab` — jump to the Element field with the text selected
- `Enter` — save the tag
- `Esc` — close without saving

## Exports

- `Cmd / Ctrl + P` — export the current view to PDF on the shot list and storyboard; on the AV Script it opens the share dialog in export mode. Not bound on call sheets — use the Export button in the call sheet's top menu bar instead.

## Notes

- `Cmd / Ctrl + N` is context-sensitive: a shot in Linear view, a banner in Production. `Shift + S` only works in Linear. The list above notes both.
- The in-app dialog (`Cmd / Ctrl + K`) shows most of these shortcuts, but not all — it has no AV Script section, and its list is maintained by hand, so it can lag behind this page.
