Mac users see `Cmd`; Windows users substitute `Ctrl`. The in-app dialog opened with `Cmd / Ctrl + K` is generated from the same reference; both stay in sync.

Phone doesn't surface a hotkeys reference — there's no in-app dialog for phone, since phone usage doesn't typically involve keyboard shortcuts. Tablet users with a hardware keyboard can use every shortcut listed here.

## Global

- `[` — toggle the left sidebar (expanded ↔ collapsed)
- `Cmd / Ctrl + K` — open the keyboard shortcuts dialog
- `Cmd / Ctrl + Shift + M` — toggle theme (light / dark)

## Shot list (Linear and Production)

- `Cmd / Ctrl + N` — add a shot (or a banner if in Production view)
- `Cmd / Ctrl + F` — enter [Focus mode](/guides/shot-list/focus-mode)
- `Shift + D` — toggle [Display Settings](/guides/shot-list/display-settings)
- `Shift + L` — toggle column layout (fit ↔ scroll)
- `Shift + M` — toggle compact ↔ expanded row height
- `Shift + S` — toggle the script sidebar in Linear view (or open the scene picker in Focus mode)
- `Shift + P` — Populate from Script
- `1` through `9` — toggle visibility of columns 1 through 9
- `Esc` — clear current selection
- `Delete` / `Backspace` — bulk delete selected items

## Focus mode

- `Cmd / Ctrl + N` — add a shot to the focused scene
- `Cmd / Ctrl + F` or `Cmd / Ctrl + B` — exit Focus mode
- `Shift + S` — open the scene picker dialog
- `→` / `←` — replace focus with the next / previous scene
- `Cmd + →` / `Cmd + ←` — add the next / previous scene to focus (multi-scene)

## Script editor

- `Cmd / Ctrl + 1` through `7` — set the current paragraph's type (scene heading, action, dialogue, …)
- `Cmd / Ctrl + B` / `I` / `U` — bold / italic / underline
- `Cmd / Ctrl + E` — centre-align

## Exports

- `Cmd / Ctrl + P` — export the current view to PDF (shot list, storyboard, or call sheet — adapts to whichever you're in)

## Notes

- Some shortcuts are context-sensitive — `Shift + S` and `Cmd + N` do different things depending on the active view. The lists above note both behaviours.
- The in-app dialog (`Cmd / Ctrl + K`) is the single source of truth and stays current with each release.
