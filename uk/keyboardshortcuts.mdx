Користувачі Mac бачать `Cmd`; користувачі Windows використовують `Ctrl`. Діалог у застосунку, що відкривається комбінацією `Cmd / Ctrl + K`, — це схожий довідник, який підтримується окремо вручну, тож він може відставати від цієї сторінки.

На смартфоні довідка з гарячими клавішами не виводиться — діалогу в застосунку для смартфона немає, оскільки використання телефону зазвичай не передбачає роботи з клавіатурою. Користувачі планшетів з апаратною клавіатурою можуть використовувати всі шорткати з цього списку.

## Глобальні

- `[` — перемикає лівий сайдбар (розгорнутий ↔ згорнутий)
- `Cmd / Ctrl + K` — відкрити діалог гарячих клавіш
- `Cmd / Ctrl + Shift + M` — перемкнути тему (світла / темна)

## Покадровка (Лінійний та Виробничий вигляди)

- `Cmd / Ctrl + N` — додати кадр (або банер у виробничому вигляді)
- `Cmd / Ctrl + F` — увійти в [Режим фокусування](/uk/guides/shot-list/focus-mode)
- `Shift + D` — відкрити [Налаштування відображення](/uk/guides/shot-list/display-settings)
- `Shift + L` — перемкнути формат стовпців (fit ↔ scroll)
- `Shift + M` — перемкнути висоту рядка (compact ↔ expanded)
- `Shift + S` — перемкнути сайдбар сценарію в лінійному вигляді (або відкрити вибір сцен у режимі фокусування)
- `1` до `9` — перемкнути видимість перших дев'яти стовпців після закріплених Status / Shot / Day
- `Esc` — зняти поточне виділення
- `Delete` / `Backspace` — масово видалити виділені елементи

## Режим фокусування

- `Cmd / Ctrl + N` — додати кадр у сфокусовану сцену
- `Cmd / Ctrl + F` або `Cmd / Ctrl + B` — вийти з режиму фокусування
- `Shift + S` — відкрити діалог вибору сцени
- `→` / `←` — перемкнути фокус на наступну / попередню сцену
- `Cmd + →` / `Cmd + ←` — додати наступну / попередню сцену до фокусу (мультисценний режим)

## Сценарний софт

- `Cmd / Ctrl + 1` до `7` — задати тип поточного абзацу (1 заголовок сцени, 2 персонаж, 3 діалог, 4 дія, 5 ремарка, 6 перехід, 7 пісенний текст)
- `Cmd / Ctrl + B` / `I` / `U` — жирний / курсив / підкреслений текст
- `Cmd / Ctrl + E` — задати поточному абзацу тип елемента «центрований текст» (не загальне вирівнювання по центру)
- `Cmd / Ctrl + I` — якщо курсор стоїть на тексті, перемикає курсив. Інакше починає імпорт сценарію (вибір файлу та [перегляд імпорту](/uk/guides/importing-scripts)) — те саме, що й кнопка **Import**, яка несе цю гарячу клавішу на своєму підписі
- `Shift + Return` — розрив рядка всередині поточного елемента
- `Shift + P` — заповнити зі сценарію (Populate from Script) — працює тут, у Сценарному софті; на покадровці не діє

### Масштаб

- `Cmd / Ctrl + =` / `Cmd / Ctrl + -` — збільшити / зменшити масштаб (крок 25%, 50–200%)
- `Cmd / Ctrl + 0` — скинути масштаб до ширини вікна
- `Cmd / Ctrl + прокручування` — масштабування біля вказівника (щипок теж працює)

### Титульна сторінка

- `Tab` / `Shift + Tab` — наступне / попереднє поле титульної сторінки з уже виділеним значенням; `Tab` на останньому полі переводить у тіло сценарію

## Редактор тегів розбору

- `1` до `9` — обрати одну з перших дев'яти категорій (поки жодне поле не у фокусі)
- `Tab` — перестрибнути в поле Element із виділеним текстом
- `Enter` — зберегти тег
- `Esc` — закрити без збереження

## Експорт

- `Cmd / Ctrl + P` — експорт поточного вигляду в PDF на покадровці та в розкадровці; в АВ-сценарії відкриває діалог спільного доступу в режимі експорту. На викличних листах не прив'язана — натомість скористайтеся кнопкою Export у верхній панелі меню викличного листа.

## Нотатки

- Деякі шорткати залежать від контексту: наприклад, `Shift + S` та `Cmd + N` виконують різні дії залежно від активного екрану. Списки вище враховують обидві поведінки.
- Діалогове вікно в застосунку (`Cmd / Ctrl + K`) показує більшість цих гарячих клавіш, але не всі — у ньому немає секції АВ-сценарію, а його список підтримується вручну, тож він може відставати від цієї сторінки.
