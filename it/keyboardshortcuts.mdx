Gli utenti Mac vedono `Cmd`; gli utenti Windows usano `Ctrl`. La finestra di dialogo in-app aperta con `Cmd / Ctrl + K` è un riferimento simile, mantenuto separatamente a mano, quindi può restare indietro rispetto a questa pagina.

Il telefono non espone un riferimento per gli hotkey — non c'è una finestra di dialogo in-app per il telefono, perché l'uso da telefono non implica tipicamente scorciatoie da tastiera. Gli utenti tablet con tastiera hardware possono usare ogni scorciatoia elencata qui.

## Globali

- `[` — attiva/disattiva la sidebar sinistra (espansa ↔ collassata)
- `Cmd / Ctrl + K` — apri la finestra delle scorciatoie da tastiera
- `Cmd / Ctrl + Shift + M` — cambia tema (chiaro / scuro)

## Lista delle Inquadrature (Lineare e Produzione)

- `Cmd / Ctrl + N` — aggiungi un'inquadratura (o un banner se sei in vista Produzione)
- `Shift + D` — attiva/disattiva le [Impostazioni di Visualizzazione](/it/guides/shot-list/display-settings)
- `Shift + L` — alterna il layout delle colonne (fit ↔ scroll)
- `Shift + M` — alterna altezza riga compatta ↔ espansa
- `Shift + S` — attiva/disattiva il pannello laterale della sceneggiatura. Solo in vista Lineare, in Produzione non fa nulla
- `1` fino a `9` — attiva/disattiva la visibilità delle prime nove colonne dopo le colonne fisse Stato / Inquadratura / Giorno
- `Esc` — cancella la selezione corrente
- `Delete` / `Backspace` — elimina in blocco gli elementi selezionati

## Editor di Sceneggiatura

- `Cmd / Ctrl + 1` fino a `7` — imposta il tipo del paragrafo corrente (1 intestazione di scena, 2 personaggio, 3 dialogo, 4 azione, 5 parentetica, 6 transizione, 7 versi)
- `Cmd / Ctrl + B` / `I` / `U` — grassetto / corsivo / sottolineato
- `Cmd / Ctrl + E` — imposta il paragrafo corrente al tipo di elemento testo centrato (non un toggle di allineamento generale)
- `Cmd / Ctrl + I` — con il cursore sul testo, attiva/disattiva il corsivo. Altrimenti avvia un'importazione di sceneggiatura (il selettore di file e la [revisione dell'importazione](/it/guides/importing-scripts)) — come il pulsante **Import**, che porta la scorciatoia sulla sua etichetta
- `Shift + Return` — interruzione di riga all'interno dell'elemento corrente
- `Shift + P` — Popola da Sceneggiatura (funziona qui nell'Editor di Sceneggiatura; inerte sulla lista delle inquadrature)

### Zoom

- `Cmd / Ctrl + =` / `Cmd / Ctrl + -` — zoom avanti / indietro (passi del 25%, 50–200%)
- `Cmd / Ctrl + 0` — reimposta lo zoom all'adattamento alla larghezza
- `Cmd / Ctrl + scroll` — zoom sul puntatore (funziona anche la pinzata)

### Pagina del titolo

- `Tab` / `Shift + Tab` — campo successivo / precedente della pagina del titolo, con il valore già selezionato; `Tab` sull'ultimo campo entra nel corpo della sceneggiatura

## Editor dei tag dello spoglio

- `1` fino a `9` — scegli una delle prime nove categorie (mentre nessun campo ha il focus)
- `Tab` — salta al campo Element con il testo selezionato
- `Enter` — salva il tag
- `Esc` — chiudi senza salvare

## Esportazioni

- `Cmd / Ctrl + P` — esporta la vista corrente in PDF su lista delle inquadrature e storyboard; sullo Script AV apre la finestra di condivisione in modalità esportazione. Non è associato agli ordini del giorno — usa invece il pulsante Esporta nella barra del menu in alto dell'ordine del giorno.

## Note

- `Cmd / Ctrl + N` è context-sensitive: un'inquadratura in vista Lineare, un banner in Produzione. `Shift + S` funziona solo in Lineare. La lista sopra annota entrambi.
- La finestra di dialogo in-app (`Cmd / Ctrl + K`) mostra la maggior parte di queste scorciatoie, ma non tutte — non ha una sezione Script AV, e la sua lista è mantenuta a mano, quindi può restare indietro rispetto a questa pagina.
