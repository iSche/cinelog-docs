If you came looking for one of these, it isn't where you're looking — because it doesn't exist yet. This page is kept current so users don't waste time hunting for things that aren't there.

## Not in the app yet

- **Undo / redo on the shot list.** Edits commit immediately and sync via CineSync. There's no undo stack. If you delete the wrong scene, contact support — server-side history can sometimes recover it.

- **Copy / paste / duplicate shots or scenes.** Add a new shot via `Cmd / Ctrl + N` or the `+` button. There's no clipboard for shots or scenes.

- **Text search inside the shot list.** Use [Focus mode](/guides/shot-list/focus-mode) to filter to specific scenes, or the column visibility toggles (`1` through `9`) to narrow what's visible.

- **Range-select on touch-only devices.** `Shift + Click` ranges work on desktop and on tablets with a hardware keyboard attached. On touch-only devices, select one row at a time in selection mode.

- **Unlocking a locked script.** Once scene numbers are locked, there's no unlock — omit scenes, revise pages, or adopt new numbers through an [import](/guides/importing-scripts). That mirrors how productions actually run: renumbering after distribution is a repair job.

- **Custom breakdown categories.** The [Breakdown](/breakdown) ships with twelve fixed categories. Use Production Notes as the catch-all in the meantime.

- **Renaming or deleting a custom role.** You can create custom crew roles, but there's no rename or delete for them in the app yet — so name them the way the call sheet should print them.

## Status

This list is reviewed every quarter. Items get removed when they ship.
